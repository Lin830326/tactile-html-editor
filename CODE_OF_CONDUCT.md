# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in every project space (issues, pull requests, discussions, reviews) and when someone represents the project in public.

In short: be welcoming and respectful, assume good intent, give and accept constructive criticism gracefully, and focus on what is best for the community. Harassment, insults, sexualised language or imagery, personal or political attacks, and publishing others' private information are not acceptable.

本專案採用 Contributor Covenant 2.1 作為行為準則（[各語言譯本](https://www.contributor-covenant.org/translations/)）：請以尊重、友善的態度參與，不容許騷擾、人身攻擊或公開他人私人資訊。

## Reporting

Report unacceptable behaviour to the project maintainer privately through the repository's **Security** tab, then **Report a vulnerability** ([direct link](../../security/advisories/new)), and say in the title that it is a conduct report. Only the maintainer can read it. The project has no mailbox. For content that breaks GitHub's own rules, you can also use GitHub's **Report content** link on the comment or profile.

All reports are reviewed promptly and fairly, and the reporter's privacy is respected. The maintainer decides on the response following the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): a private correction, a warning, a temporary ban or a permanent ban.
